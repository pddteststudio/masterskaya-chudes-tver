# Мастерская Чудес — Тверь

Профессиональный демонстрационный веб-сайт-каталог для мастерской воздушных шаров «Мастерская Чудес» (`vk.com/sharik69`).

**Это независимый концепт, не официальный сайт мастерской.** Представленные товары, названия наборов и иллюстрации — авторские демонстрационные примеры. Реальный ассортимент, состав, цена, наличие, адрес, время доставки, возможность самовывоза и контакты должны быть подтверждены владельцем перед коммерческим запуском.

## Состав

- `index.html` — яркая главная с каталогом, поводами, декором и ссылками на VK.
- `catalog.html` — 12 вариантов композиций, фильтры по поводам, развёрнутые карточки, добавление в подборку.
- `decor.html` — концепты арок, фотозон и праздничного оформления.
- `create.html` — выбор палитры, повода, ориентировочного количества шаров, типа акцента, пожеланий, даты и времени. Выбранные из каталога товары добавляются к тексту заявки.
- `delivery.html` — этапы заказа, FAQ, контакты.
- `assets/style.css`, `assets/app.js`, `assets/products.js` — исходные стили, скрипты и данные.
- `assets/art/` — 14 оригинальных SVG-иллюстраций, созданных специально для сайта.
- `preview-offline.html` — автономная главная страница со встроенными иллюстрациями, стилями и скриптами; для автономного просмотра других страниц есть `preview-catalog-offline.html`, `preview-decor-offline.html`, `preview-create-offline.html`, `preview-delivery-offline.html`.
- `previews/` — скриншоты и отчёт визуальной/функциональной проверки `qa.json`.
- `СООБЩЕНИЕ_ДЛЯ_VK.txt` — предложение владельцу.

## Как посмотреть

Распакуйте архив и откройте `index.html` в браузере (все файлы из `assets` должны остаться рядом). Альтернатива: откройте `preview-offline.html`, который не зависит от внешних ассетов, но навигация в нём ведёт на обычные страницы сайта.

## Как опубликовать на Vercel

1. Загрузите содержимое каталога проекта в новый репозиторий GitHub, `index.html` должен находиться в корне.
2. Vercel → Add New → Project → импортируйте репозиторий.
3. Выберите **Framework Preset: Other**. Build Command не нужен, Output Directory оставьте пустым.
4. Deploy — после этого ссылки между страницами и исходные иллюстрации будут работать без сервера приложения.
5. До продажи сайт должен оставаться демонстрационным и закрытым от индексации (`noindex,nofollow` и `robots.txt`).

## Технические особенности

- HTML, CSS, vanilla JavaScript, никаких внешних сборщиков и серверных зависимостей.
- Каталог: 12 карточек, 6 фильтров, модальное окно товара.
- Корзина-подборка: добавление, удаление, изменение количества; сохраняется в `localStorage` браузера. Нет оплат, резервирования товаров и передачи данных третьим лицам.
- Конструктор: 6 палитр, анимации, динамическая иллюстрация выбранного цвета, подбор набора и дата. Генерирует текст заявки.
- **Отправка заказа не автоматическая.** Посетитель должен скопировать текст, перейти в `https://vk.me/sharik69` и отправить его самостоятельно. Ничего не бронируется, пока мастерская не подтвердит заказ.
- Дата и время — пожелания, а не проверенные свободные слоты доставки.
- Стоимость по запросу: нет поддельного прайса и ложных остатков. Нет ложных гарантий и отзывов.
- Фотографии реальных работ можно добавить только после согласования прав на использование.
- Формы не запрашивают персональные данные, не ведут скрытый сбор и не используют внешнюю аналитику.
- Кодировка UTF-8, семантическая разметка, доступные кнопки/подписи, поддержка `prefers-reduced-motion`.
